# 📄 Contract Risk Intelligence System

## Overview

This project is a Streamlit-based web application that analyzes legal contracts in PDF format. It extracts contract text, detects clauses, classifies them into different categories, identifies risk levels, and displays the results through an interactive dashboard.

## Features

- Upload PDF Contracts
- Automatic Clause Detection
- Clause Type Classification
- Risk Level Detection
- Contract Risk Score
- Interactive Dashboard
- Executive Summary
- CSV Report Download

## Technologies Used

- Python
- Streamlit
- PyMuPDF
- Pandas
- Plotly

## Run the Project

```bash
pip install -r requirements.txt
streamlit run app.py
